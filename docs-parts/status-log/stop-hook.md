what: B-0012 item 3, the Stop hook. `adapters/claude_code/stop_hook.py` is a Claude Code `Stop` hook (Stop is a hook event of the installed Claude Code 2.1.330, checked in its binary; the output is the documented `{"decision": "block", "reason": "..."}`). It reads the PR queue as `umwayi pr queue next --check` does and keeps a session from ending its turn while fewer than `keep_ready` branches are ready and a free task is pending, at most three times in a row per session (a count in `.umwayi/stop-hook/SESSION_ID`, deleted when the queue is no longer low), then lets it stop. It lets the session stop when the kill switch is on or unreadable, when every pending task is blocked, on a bad input, another event, a SubagentStop or a broken `pr-queue.md`: it only nudges and fails open, never exits 1 or 2, and writes nothing but the count. `stop-hook.example.json` is the settings entry for the owner to copy; no settings file is edited. It does not change the start of a helper. Cooperative: a helper that ignores its hooks is not stopped. A new adapter: owner stop.
tests: `tests/adapters/test_stop_hook.py` (the block, three blocks then the fourth let through, the reset, the kill switch, blocked tasks, bad input, the real script).
