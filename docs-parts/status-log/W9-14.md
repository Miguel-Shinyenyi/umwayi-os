what: W9.14, `umwayi goal retry G T --budget-uu N [--goal-budget-uu M]`: the owner's retry of one task that failed or was stopped. It needs a terminal and starts nothing. The retry is a new task with the next free id from the same packet (goal, context, checks, size, files, model and effort) and the owner's new budget, queued in the place of the task it replaces in the run order, so the later tasks still wait for it; the replaced task keeps its file, state, spend and worktree. One logbook entry with ids, the packet hash and numbers. The goal budget must cover the planning budget, everything spent, what the other unfinished tasks may still spend and the new budget; only `--goal-budget-uu` raises it, never lower. `goal status` and `report` say `retried as T-03`; `repair` rebuilds a retry file whose write failed after its entry. No automatic retry (W9.R6.5); rules, steering, the rules gate and the workflows are unchanged.
