what: W19 part 5: `umwayi stalls check EVENTS.json` and `umwayi/stalls.py`, the Kiro Crew lessons as checks. Small pure functions over a JSON list of builder events report one line per finding: a running builder with no push or real event for 30 minutes (stall), the same error signature twice in a row (stop), an owner approval with no answer at or past its deadline or answered after it (counts as No, never Yes), and a status with no last event time (refused). Exit 0 nothing found, 3 any finding, 2 unreadable or malformed input, 64 usage, never 1. It reads one file, changes nothing, never repeats file text, takes the time as an argument (an injected clock in the tests) and is on no schedule. Page: `docs/stalls.md`. Nothing is wired into guidance, concerns, routing, agents files, steering files or the backfill.
