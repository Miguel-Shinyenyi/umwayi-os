what: W16: `tools/board_status.py`, a read only status script for the guide's every cycle. It lists the open pull requests of Miguel-Shinyenyi/umwayi-os, one line each: number, title, head branch, time of the last commit, CI state of the head commit (green, red, running, or none when there is no check suite), whether the branch has the newest main, and mergeable or conflict, then a stall line for any branch with no new commit for 30 minutes. Standard library only (urllib over HTTPS to api.github.com, no token, a timeout on every request). It fails closed: an HTTP error, a rate limit, bad JSON, a missing field or a mergeable flag GitHub has not worked out prints one line and exits 2. The tests are in `tests/test_board_status.py` with a fake HTTP layer (normal, rate limited, bad JSON, no open pull requests, no checks, a red check, and more); it is in `tools/ci_map.json` and `tools/ci_shards.json`.
