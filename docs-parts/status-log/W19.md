what: W19: `tools/backfill_history.py`, a read only script that turns the public pull request and CI history of Miguel-Shinyenyi/umwayi-os into derived records. It writes one JSON lines file the caller names (`--out`, with `--max` and `--after`): a header (schema version, date, complete) and one object per pull request sorted by number with a fixed list of keys: number, merged, created and merged dates, files changed, lines added and removed, commits, reviews, review comments, check run counts by conclusion, failed then re run checks, minutes to merge, labels and a task kind from the title prefix. Never a title, body, comment, branch, file or author name. A field GitHub does not give is `unknown`. Same limits as the board status: standard library only, https to api.github.com only, 15 second timeout, no token, no redirect, 60 requests an hour honored with a clean stop, exit 2 on any failure, 64 for usage. The tests in `tests/test_backfill_history.py` use a fake GitHub server on 127.0.0.1 (normal, unknown fields, rate limit, timeout, bad JSON, planted private text, other host refused, no token, stable output). It is in `tools/ci_map.json` and `tools/ci_shards.json`. Nothing in `umwayi/` changed.
