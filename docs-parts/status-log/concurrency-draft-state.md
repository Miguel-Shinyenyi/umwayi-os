what: The draft race (CHANNEL.md B-0005, W2). On pull request 217 the real run of a pull request marked ready was cancelled by the skipped run of the draft push a second later, because the workflow's concurrency group was the pull request number alone and a newer run cancels the older. The draft state is now part of the group: `${{ github.workflow }}-${{ github.event.pull_request.number || github.sha }}-${{ github.event.pull_request.draft }}`. A draft run and a ready run of one pull request are in different groups and cannot cancel each other; two ready runs still share a group, so a newer push still cancels the older run; a push to main still has its own group per commit and is never cancelled. The header comment gives the reason. A change to a workflow file: owner stop. Not proven on GitHub until a draft is pushed and marked ready at once on a real pull request after this merges.
