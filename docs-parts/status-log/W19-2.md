what: W19 part 2: the concerns record checker. `umwayi concerns check PATH` (`umwayi/concerns.py`) reads a markdown table with the columns number, concept, answer, reason, evidence, date and refuses a record that does not have exactly one row for each of the 111 engineering concepts (the fixed list is in the module), each with an answer of Applies, Not applicable or Deferred and a non empty reason. An Applies row needs evidence: a regular file that exists inside the repo, with no `..` part, no absolute path and no link that leads out. A malformed date, a wrong column count, a wrong header or a record that is unreadable, too big or not UTF-8 is also refused. One line per failure, exit 2 on any failure, 0 when well formed, 64 for usage; it never repeats text from the file and changes nothing. It checks the form only, never that the content is true, and no job, timer or workflow runs it. The tests are in `tests/test_concerns.py`; `tests/test_exit_codes.py` lists the command; it is in `tools/ci_map.json` and `tools/ci_shards.json`; `docs/concerns.md` is new.
